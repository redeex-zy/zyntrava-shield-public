# Draft contribution opportunities

These have not been posted or assigned on GitHub. Use synthetic/local testing only.

## Three beginner-friendly issues

1. **Improve missing-model diagnostics.** Reproduce missing/corrupt assets and busy
   ports in disposable fixtures. Keep errors non-sensitive and startup fail-closed.
   Acceptance: actionable error, retained partial evidence, no raw path/token leak,
   no policy/runtime fallback, regression test and troubleshooting update.
2. **Test CLI help on a no-agent installation.** Verify base help is usable and
   optional examples explain the exact dependency setup. Acceptance: a clean base
   venv test, explicit scripted/neural labels and no automatic provider credentials.
3. **Expand keyboard/empty-state checks.** Use the authenticated local dashboard
   with dummy events. Acceptance: clear disconnected state, visible focus and one
   browser regression; no invented metrics or claims of full WCAG certification.

## Two research-oriented opportunities

1. **Independent multi-value recovery evaluation.** Preregister task contracts and
   impossible/cancelled controls; separate progress metadata from retry cues. Use
   actual proposals/effects and unchanged budgets. Acceptance includes negative
   results, duplicates/uncertainty, held-out authorship and no default-mode promotion.
2. **Native Linux inference behind the same broker.** Investigate an owned pinned
   local model process with no arbitrary shell/MCP tools. Measure resource fit and
   process cleanup; keep OS containment claims scoped. Acceptance requires a real
   model run, fail-closed regressions and explicit unsupported configurations.

No novelty, performance advantage or production readiness is assumed by these tasks.
