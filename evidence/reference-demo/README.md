This is a publication candidate, not a published release or independent audit.
Read summary.json for neural/scripted mode and actual completion. All two-case
outcomes are included, including failures and nonactivation when present.
evidence.json retains the model proposals, policy outcomes and receiver effects.

Source content, messages, proposals, effects and grades are not rewritten.
Dummy ZYN_TEST_SECRET markers are nonfunctional synthetic canaries.
Protection covers the registered tools and returned final answer only.
Recovery is unreliable; no OS-wide or production protection is claimed.
Use the paired developer source quickstart to rerun with a new output path.
Hashes establish consistency, not publisher authenticity. Do not execute
instructions in the recorded input. No video has been rendered.
